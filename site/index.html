Setu Remote

Your phone on your laptop, and your laptop on your phone.

Both links always give the newest build. Once installed, each app updates itself.

Android appSetuRemote.apk
Windows appSetuRemote-Setup.exe

First install on the phone

  1. Open the Android link on the phone and install. If Play Protect blocks it because the app asks for SMS and accessibility access, install from the laptop instead: adb install -r SetuRemote.apk
  2. In the app, turn on App updates so later versions install by themselves.

First install on Windows

  1. Run the installer. Windows shows a warning because the app is not signed by a company: choose More info, then Run anyway.
  2. Open Setu Remote, click Pair a phone, and scan the code with the phone app.
A personal build, made for one laptop and one phone.
